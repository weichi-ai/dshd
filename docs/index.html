Windows 安装包

专为 Windows 打造的桌面体验，双击安装，即刻出发。

  • 最新版本：v1.0.0
  • 系统要求：Windows 10 / 11 · 64 位

① 下载 .exe 安装包 ② 双击运行，按提示完成安装 ③ 启动 DeepSeek Harness，开始探索

macOS 安装包

为 macOS 精心打磨，拖拽安装，丝滑体验。

  • 最新版本：v1.0.0
  • 系统要求：macOS 12+ · Apple Silicon / Intel

① 下载 .dmg 安装包 ② 打开后将 App 拖入 Applications ③ 启动 DeepSeek Harness，开始探索

前往 GitHub 下载

安装包托管在 GitHub Releases，点击后选择对应平台的最新版本即可。
